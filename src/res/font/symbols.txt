# ============================================================
# Receiver UI 字体符号集（单一事实来源）
# ============================================================
# 使用规则：
# 1. 本文件是三个 HarmonyOS 字体（12/14/16px）唯一读取的字符来源。
#    修改本文件后必须重新生成字库，否则新增字符不会显示。
# 2. Receiver 界面/提示新增中文文字时，把新出现的字符追加到本文件
#    （注释行以外的内容行），重复字符会被自动去重排序。
# 3. 重新生成字库（在 code/ 仓库根目录执行）：
#      powershell -ExecutionPolicy Bypass -File docs\tools\gen_fonts.ps1
#    脚本会读取本文件（UTF-8）、调用 lv_font_conv 生成三个字号、
#    执行 include 补丁并自动校验所有字符落在正确码点，校验失败会报错退出。
# 4. 禁止手工编辑生成的 lv_font_harmonyos_*.c 文件。
# 5. 禁止把中文字符写进 PowerShell 脚本字面量再传给 lv_font_conv：
#    PowerShell 5.1 会把无 BOM 的 UTF-8 脚本按 GBK 读取，字符在传递前
#    就会被破坏（曾导致整个字库乱码）。字符只能经由本文件传递。
# ============================================================
